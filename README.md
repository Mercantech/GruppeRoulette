# GruppeRoulette

En over-the-top gruppedanner forklædt som en enarmet tyveknægt. Tilføj en klasseliste, træk tre navne ad gangen, og følg med i resterende deltagere og dannede grupper.

## Start med Docker

```bash
docker compose up --build
```

Åbn derefter [http://localhost:8080](http://localhost:8080).

## Funktioner

- Tilføj navne enkeltvis eller som en hel liste
- Tilfældig udtrækning uden gentagelser
- Unikke, fjollede gruppenavne bygget af sammensatte ord
- Tusindvis af mulige gruppenavne med mulighed for at rulle et navn om
- Interaktivt håndtag, der kan trækkes med mus eller finger
- Flere runder, hvor tidligere makkerpar aldrig placeres sammen igen
- Animerede ruller, lyde, lys og konfetti
- Overblik over resterende navne og færdige grupper
- Kopiér alle grupper til udklipsholderen
- Automatisk lokal lagring i browseren
- Responsivt design og understøttelse af reduceret bevægelse
